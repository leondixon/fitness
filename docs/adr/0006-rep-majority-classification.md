# V1 lifting Classification is a rep majority

For now, a lifting Session is strength if most working sets are ≤5 reps, otherwise hypertrophy. Yoga classifies as mobility; a run as conditioning. A more complex classifier is expected later; this rule exists so Lookback is inspectable. If Results miss the Pick (asked strength, logged hypertrophy), Lookback still records what happened — no warning, no double-count.
