# Exercise catalog is not athlete-authored

Picks choose the Exercise deemed suitable for the scenario from a populated catalog, not from a static athlete list and not because it already has History. Trend transfers when two Exercises share the same main muscle activation (e.g. both ~90% the target muscle), not merely the same Working group. Results remain stored per Exercise so a novel choice grows its own History. The alternative was preferring known Exercises so calibration stays on one lift. The activation map itself is the research piece in ADR-0007.
